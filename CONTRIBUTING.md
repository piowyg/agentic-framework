# Contributing

## Development

```bash
npm test              # vitest (fake harness, zero tokens)
npm run typecheck
npm run docs          # regenerate docs/reference from the JSON Schema and the CLI definitions
npm run ci            # typecheck + tests + docs/reference freshness check
npm run dev -- status # CLI without a build (tsx)
```

`src/` layout: `config/` (schema, layers, profiles, model registry), `harness/` (interface: building the command
and reading the result, fake, CLI adapters), `sandbox/` (where a session runs: host / container, collecting artifacts
from `out/`), `orchestrator/` (artifacts, state, gates, flow runner), `review/` (report parsing), `cli/`, `doctor.ts`.

## Documentation

- English (`README.md`, `docs/en`) is the source of truth. Update it with your change.
- The Polish translation (`README.pl.md`, `docs/pl`) is optional for contributors; the maintainer keeps it in sync.
  A page without a Polish twin is fine.
- `docs/reference` is generated by `npm run docs` from the descriptions in `src/config/schema.ts` and
  `src/cli/program.ts`; don't edit it by hand.

## Pull requests

Issues and pull requests are welcome. Every pull request needs the maintainer's approval before it is merged, and CI
on pull requests from forks runs after a maintainer approves it. Keep a pull request to one change and run
`npm run ci` before opening it.

Security issues: see [SECURITY.md](SECURITY.md), don't open a public issue.
