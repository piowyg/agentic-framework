# Security policy

Agentic Framework runs AI agents that read and change code, so sandbox escapes, secret leaks and ways around the
permission settings are security issues. [docs/en/security.md](docs/en/security.md) describes the threat model.

## Reporting a vulnerability

Report it privately through GitHub: **Security → Report a vulnerability** on this repository. Please don't open a public
issue for it.

Include what you ran, what the agent could do that it shouldn't, and the version or commit. You'll get a reply within
7 days.

## Supported versions

Only the latest commit on the default branch gets fixes.
